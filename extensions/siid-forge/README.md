# SIID Forge

The Salesforce development framework engine for **SIID** (Salesforce Intelligence
Integrated Development).

SIID Forge is a built-in, CLI-powered core extension. It owns all access to the
`sf` CLI and exposes a single internal API that other SIID extensions build on —
so features never talk to the CLI directly.
